# EcoTrack - Sustainability App

EcoTrack is a comprehensive sustainability app that helps users track their environmental impact, participate in eco-friendly challenges, and build sustainable habits. The app provides personalized recommendations and connects users with a community of like-minded individuals.

## Features

- **Carbon Footprint Tracker**: Log daily activities like transportation, energy use, and consumption to calculate your carbon footprint
- **Sustainability Challenges**: Join weekly or monthly challenges to build eco-friendly habits and earn rewards
- **Eco-Friendly Tips**: Get personalized recommendations based on your activity patterns and location
- **Community Features**: Connect with others, share progress, and participate in friendly competition

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Charts**: Recharts with shadcn/ui chart components
- **Icons**: Lucide React
